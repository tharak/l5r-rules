# Repository workflow

After completing requested changes and the relevant checks, commit and push the work to the current branch's configured remote unless the user explicitly asks otherwise. This is the user's standing preference; no separate confirmation is needed for routine commits and pushes.

Preserve unrelated local changes and avoid including them in a commit without authorization.

# Rules source priority

Applicable official Legend of the Five Rings fourth-edition errata takes precedence over conflicting printed rules, iOS JSON catalogs, and wiki content. When errata revisions conflict, use the latest applicable official correction. Preserve clan, era, and other context-specific distinctions, and record the errata reference when reconciling a rule.
